# Életkori áttekintés

Az életkori oldalak tág, egymásba érő időszakokat mutatnak be. Nem ellenőrzőlisták: az egyéni fejlődés változatos. A [CDC mérföldkőlistái](https://www.cdc.gov/act-early/milestones/) tájékozódási pontok, nem diagnosztikai tesztek.

Az oldalak a bal oldali menüben érhetők el. Ha bizonytalan vagy vagy készségvesztést látsz, [kérj szakmai segítséget](../06_fejlodes/variabilitas.md).
